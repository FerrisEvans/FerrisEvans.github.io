本文说明内置数组、数组到指针的转换以及数组的生命周期管理。完整的 C 示例用于演示元素访问，周围的说明会区分 C 与 C++ 的相关规则。

## 声明和访问

数组是 C++ 表示内存中对象序列最基本的方式。如果你用到的只是内存中一个固定大小、固定元素类型的序列，那么数组完全满足你的要求。

假设有类型 `T`，`T[size]` 的含义是“包含 `size` 个 `T` 类型元素的数组”。元素的索引范围是 `0` 到 `size-1`。

你可以使用下标运算符和指针访问数组元素。下标引用和间接访问表达式是等价的。

C++ 内置数组声明中的元素数量必须是常量表达式。如果需要在运行时决定或改变元素数量，可以使用 `std::vector`。

> [!CAUTION]
> 越界访问内置数组属于未定义行为，可能导致严重的程序错误。C++ 内置数组不保证运行时边界检查。

将下面的示例保存为 C 源文件，并使用 C 编译器编译。程序依次输出第一个元素、数组起始地址、第一个元素和第二个元素。其中数值输出为 `1`、`1` 和 `2`，地址则随运行而变化。

```c
#include <stdio.h>

int main(void) {
    int a;
    a = 0;
    int arr[] = {1, 2, 3, 4};
    printf("%d\n", *arr); /* 1 */
    printf("%p\n", (void *)arr); /* 地址随运行而变化。 */
    printf("%d\n", arr[0]); /* 1 */
    printf("%d\n", *(arr + 1)); /* 2 */

    return 0;
}
```

在上述代码中，我们把变量 `a` 称为标量，因为它是个单一的值，类型是一个整数。
而 `arr` 是一个数组，它是一些值的集合，下标用于标识该集合中某个特定的值。
如 `arr[0]` 表示 `arr` 中的第一个值，`arr[2]` 表示 `arr` 中的第三个值。

`arr[0]` 的类型是整型，那么 `arr` 的类型又是什么呢？
在 C 语言中，大多数使用数组的表达式会将数组转换为指向首元素的指针，指针类型取决于数组元素类型。

数组和指针并不相同。指针是标量值，数组则包含确定数量的元素；编译器知道数组的元素类型和大小，但不保证发现所有越界下标。
编译器记录数组的这些属性，在表达式需要数组到指针的转换时，产生指向首元素的指针值。

> [!TIP]
> 这种转换产生的是指针值，不是一个可重新赋值以移动数组的独立指针变量。数组的存储位置取决于其存储期和分配方式；自动数组和动态分配数组的地址，并不是在链接时就固定的。

C++ 的内置数组本质上是语言的一种底层功能，我们常常用数组来实现标准库 `vector` 和 `array` 等更高层级上的、行为定义更好的数据结构。
内置数组不能整体赋值；在语言规则要求的场合，数组表达式会隐式转换为**指向数组首元素的指针**。

> [!WARNING]
> 要避免在接口中使用数组，因为数组名隐式转换是 C 代码和 C 风格的 C++ 代码中很多错误的根源。
> 如果数组是在自由存储[^free_store]上通过 `new[]` 分配的，切记在最后一次使用后通过对应指针执行 `delete[]`。

最简单可靠的办法是用资源句柄（`std::string`、`std::vector` 或 `std::unique_ptr<T[]>`）控制自由存储上的数组的生命周期。

> [!CAUTION]
> 如果你是静态[^static]分配数组或者是在栈上分配数组，不要对它执行 `delete[]`。

[^free_store]: 用 `new` 和 `delete` 直接控制其生命周期的对象。注意，自由存储并不等价于堆。
[^static]: 在全局作用域或命名空间作用域中声明的对象以及在函数或类中声明的 `static` 成员，只被创建并初始化一次，并且在程序结束之前保持存活。
