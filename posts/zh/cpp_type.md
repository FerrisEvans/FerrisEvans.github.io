## 布尔类型

一个布尔变量（`bool`）的取值或者是 `true` 或者是 `false`，常用于表示逻辑运算的结果。
根据定义，当我们把布尔值转换成整数时，`true` 转为 1，而 `false` 转为 0。反之，整数值也能在需要的时候隐式地转换成布尔值，其中非 0 整数对应 `true`，而 0 对应 `false`。

```c++
bool b1 = 7;
bool b2{7}; // 错误：发生了窄化转换

int i1 = true;
int i2{true};

bool a = true;
bool b = true;

bool x = a + b; // true
bool y = a || b; // true
bool z = a - b; // false
```

如果你既想使用 `{}` 初始化器列表防止窄化转换[^narrowing_conversion]的发生，同时又确实想把 `int` 转换成 `bool`，可以显式写出比较条件。

```c++
void f(int i)
{
  bool b{i != 0};
}
```

如有必要，指针也能被隐式地转换成 `bool`。其中，非空指针对应 `true`，值为 `nullptr` 的指针对应 `false`。

```c++
void g(int *p)
{
  bool b = p; // 转换为 true 或 false
  bool b2{p != nullptr}; // 显式检查指针是否为空
  
  if (p) // 等价于 p != nullptr
  {}
}
```

> [!TIP]
> 我更倾向于使用 `if (p)`，因为它简洁地表达了“`p` 是否非空”。但无论 `if (p)` 还是 `if (p != nullptr)`，都不能证明指针所指的对象仍然有效。

## 字符类型

在 C++ 中，`char` 恰好占 1 字节，所以 `sizeof(char)` 始终等于 1。一个字节包含多少位则取决于实现：
一个字节至少有 8 位，常见平台采用 8 位字节。以字节表示的大小和每字节的位数是不同概念。
`char` 能存储一个字节的字符数据。许多实现对基本字符采用与 ASCII 兼容的编码。

```c++
unsigned char c1 = 64; // 定义良好：在任何情况下，char 都至少包含 8 个二进制位，能够存储 64
unsigned char c2 = 1256; // 结果取决于 char 的位数；如果 char 占 8 位，则转换后为 232
```

`char`：普通字符类型，用于程序文本中的字符。它表示实现所采用的字符编码中的值，通常占 8 位。

`signed char`：与 `char` 大小相同，明确为有符号类型，可以存放负值、零和正值。

`unsigned char`：与 `char` 大小相同，明确为无符号类型。

`wchar_t`：用于宽字符。其尺寸取决于实现，用于支持该实现采用的宽字符编码。

`char16_t`：用于 UTF-16 代码单元。

`char32_t`：用于 UTF-32 代码单元。

> [!NOTE]
> 实现可以让 `char` 与 `signed char` 或 `unsigned char` 具有相同的表示和取值范围，但它们仍然是 3 种不同的类型，指向它们的指针不能互换。

在编程环境所用的字符集中，每个字符都对应一个整数值。
下面的函数从标准输入读取字符并输出对应的整数值，需要包含 `<iostream>`；示例省略了调用它的主函数。

```c++
#include <iostream>

// 此处省略调用 intval() 的 main() 函数。
// 查看任意字符对应的整数值
void intval()
{
  for (char c; std::cin >> c; )
    std::cout << "the value of '" << c << "' is " << int{c} << '\n';
}
```

> [!WARNING]
> 最好不要对对象的表现形式作出任何主观假设，对于字符尤其如此。

|    符号/前缀     |       含义       | 示例        |
|:------------:|:--------------:|:----------|
|     `'`      |     `char`     | `'c'`     |
|     `u'`     |   `char16_t`   | `u'c'`    |
|     `U'`     |   `char32_t`   | `U'c'`    |
|     `L'`     |   `wchar_t`    | `L'c'`    |
|     `"`      |      字符串       | `"mess"`  |
|     `R"`     |     原始字符串      | `R"(\b)"` |
| `u8"` `u8R"` |   UTF-8 字符串    | `u8"foo"` |
|  `u"` `uR"`  |   UTF-16 字符串   | `u"foo"`  |
|  `U"` `UR"`  |   UTF-32 字符串   | `U"foo"`  |
|  `L"` `LR"`  | `wchar_t` 字符串  | `L"foo"`  |

表中的“字符串”是指字符串字面量[^string_literal]，而非数据类型 `std::string`。

## 浮点数类型

- `float`：通常采用单精度表示
- `double`：通常采用双精度表示，精度不低于 `float`
- `long double`：精度不低于 `double`，具体表示取决于实现

|   符号    | 位置 |   含义    | 示例      |
|:-------:|:--:|:-------:|:--------|
| `f` `F` | 后缀 | `float` | `10.0F` |
| `e` `E` | 中缀 | 浮点指数 | `10e-4` |
|   `.`   | 中缀 | 小数点 | `1.2`   |

> [!TIP]
> 对于大多数应用来说，我们用 `bool` 表示布尔值、用 `char` 表示字符、用 `int` 表示整数值、用 `double` 表示浮点数。其他基本类型可以看作是上述类型的变形，
> 只有当程序在性能优化、兼容性或其他方面有所要求时才会用到；一般情况下，前面四种类型已经足够了。

## `void` 类型

- 作为函数的返回类型以说明函数不返回任何实际的值。
- 作为指针的基本类型部分以表明指针所指的类型对象未知。

```c++
void f();
void *ptr;
```

## 类型大小

$$
1\text{ byte} = 8\text{ bits}
$$

上面的等式描述常见的 8 位字节。按照 [C++ 标准的基本类型规则](https://eel.is/c++draft/basic.fundamental)，很多重要细节取决于具体实现，并与运行程序的硬件系统密切相关。

C++ 规定 `char` 至少占 8 位，`short` 至少占 16 位，`long` 至少占 32 位。

`int` 的实际大小取决于实现，设计目的是适合目标机器上的整数运算；常见实现中它占 4 字节。

> [!WARNING]
> - `char` 通常占据 8 位，但也确实存在 `char` 占 32 位的机器。
> - 我们绝不能假定 `int` 和指针的尺寸一样大，因为在很多机器上（64 位体系结构）指针的尺寸比整数大。

[^narrowing_conversion]: 丢失信息的类型转换。
[^string_literal]: 双引号内的字符序列；生成的数组包含一个结尾空字符 `\0`。
