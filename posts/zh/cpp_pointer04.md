## 左值与右值

为了能更清楚的解释指针，我们还需要了解左值（lvalue）和右值（rvalue）。这两个术语是多年前由编译器设计者所创造并沿用至今的，尽管它们的定义并不与 C 语言严格吻合。

直观地说，左值标识一个对象，其中可修改的左值可以出现在赋值符号左侧。赋值符号右侧则可以使用左值或右值，并进行所需的转换。

下面假定 `a` 和 `b` 已声明为整数，且 `b` 已初始化：

```c
/* 此处省略变量声明和外围函数。 */
a = b + 25;
```

`a` 是个左值，`b + 25` 是个右值。

它们可以互换吗？原先用作左值的 `a` 可以放到右侧使用，但 `b + 25` 不能放到左侧，因为它不标识一个可以被赋值的对象。因此，这样的赋值语句是非法的。

> [!TIP]
> 当计算机计算 `b + 25` 时，结果当然需要以某种形式保存，但这并不会让表达式变成左值：它计算一个值，而不是标识一个对象。数值字面量同样不是左值；但不能概括为所有字面量都不是左值，因为字符串字面量标识数组。

我们似乎可以得出这样一个结论：变量可以作为左值而表达式不可以。但是这个结论并不准确。如下赋值语句的左值就是表达式。

下面是独立的片段。`b` 初始化为 `0`，确保 `b + 10` 是有效下标；两次赋值分别把 `a[10]` 设为 `0`，把 `a[0]` 设为 `10`。

```c
/* 将这些语句放在函数内；此处省略外围函数。 */
int b = 0;
int a[30];
a[b + 10] = 0;

int *p;
p = a;
*p = 10;
```
