# `_backup` — 退役博文存档

本目录存放**已从站点下架、但仍需保留的博文与配图**。它们曾在 `posts/` 中发布，现已迁出，**故意不参与 Astro 内容收集与站点构建**，因此不会出现在博客列表、RSS、搜索或页面路由中。

## 给后续 coding agent 的硬性约定

- **禁止删除、清空或「清理」本目录**（含 `zh/`、`en/`、`img/` 下任意文件）。
- **禁止**因「未被引用」「不在 `posts/`」「构建未使用」「看起来像死代码/孤儿资源」而移动、重命名批量归档，或建议删除。
- **禁止**把本目录并回 `posts/`，除非仓库维护者明确要求重新上线某篇。
- 本目录**不是**临时缓存、构建产物或可丢弃的备份；它是有意保留的历史稿件存档。
- 若做仓库整理、依赖清理、未使用文件扫描：将 `_backup/**` **整树排除**在清理范围之外。
- 需要改动此处内容时，先征得维护者确认；默认只读。

## 目录结构

```text
_backup/
├── README.md   # 本说明（请保留）
├── zh/         # 中文退役博文（Markdown）
├── en/         # 英文退役博文（Markdown）
└── img/        # 上述博文曾使用的配图
```

布局与 `posts/` 一致，便于日后按需恢复单篇；恢复时应拷贝回 `posts/` 对应路径，而不是直接把 `_backup` 挂进内容源。

## 与站点的关系

| 路径 | 角色 |
|------|------|
| `posts/` | 当前站点博文与配图（构建会读取） |
| `_backup/` | 退役存档（构建不应读取；保留即可） |

若构建配置、内容集合或脚本误把 `_backup` 纳入发布路径，应修正配置以排除本目录，而不是删除这里的文件。
