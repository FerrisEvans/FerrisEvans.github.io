## Attributes

| Abbreviation  | Meaning        |      Full name      | Notes                     |
|:---:|:----------|:------------:|:-----------------------|
| STR | Strength        |   strength   | Attack power, carrying capacity                 |
| VIT | Stamina, life force, vitality |   vitality   | Health and stamina gained on level-up; some games use it for constitution |
| CON | Constitution        | constitution |                        |
| INT | Intelligence        | intelligence | Magic attack                   |
| WIZ | Wizardry, magic     |   wizardry   | Related to magic attack, similar to INT          |
| WIS | Wisdom, perception     |    wisdom    | Mana for support magic                 |
| MND | Mental strength, mind    |     Mind     | Magic defense                   |
| SPI | Spirit        |    spirit    |                        |
| MEN | Spirit        |  mentality   |                        |
| PIE | Piety        |              | Mana gained on level-up, mana regeneration          |
| DEX | Dexterity        |  dexterity   | Attack speed, defense, evasion               |
| SPD | Speed        |    speed     | Movement speed, attack speed, casting speed, channeling speed        |
| AGI | Nimbleness, agility    |   agility    | Evasion chance                    |
| AGL | Evasion chance       |              |                        |
| LUK | Luck        |     luck     |                        |
| PER | Personality        | personality  |                        |
| Chr | Charm        |   charming   |                        |
| KAR | Fate, karma     |    Karma     |                        |

## Combat stats

|      Abbreviation       | Meaning             |        Full name        | Notes                    |
|:-------------:|:---------------|:----------------:|:----------------------|
|      HP       | Health, hit points         |   health point   |                       |
|    MP/Mana    | Mana            |    mana point    |                       |
|      SP       | Skill energy, skill experience, stamina |                  | Some games use SP in place of MP; it can be spent or accumulated |
|      CP       | Rage, combat points       |                  | Often must fill completely before a special move can be used         |
|      DAM      | Attack power            |      damage      |                       |
|      ATK      | Physical attack power          |      attack      |                       |
|   MATK/MAG    | Magic attack power          |   magic attack   |                       |
|      DEF      | Physical defense          |     defence      |                       |
|     MDEF      | Magic defense          |  magic defence   |                       |
| AVO/AVD/AVOID | Evasion chance            |                  |                       |
|      AAR      | Physical attack evasion chance        |                  |                       |
|      SAR      | Magic attack evasion chance        |                  |                       |
|  RESIST/RES   | Magic resistance          |                  |                       |
|      WSP      | Weapon attack speed         |   weapon speed   |                       |
|     CT/CR     | Critical hit chance        |     critical     |                       |
|      RNG      | Attack range           |      range       |                       |
|      CD       | Cooldown           |    cool down     |                       |
|   MOV/MOVP    | Movement allowance            | movement (point) | Distance that can be moved each turn              |
|      HIT      | Hit chance, consecutive hits        |       hit        |                       |
|     COMBO     | Combo count            |      combo       | Most games now use “combo” to describe consecutive hits  |
|      KB       | Break value            |   attack break   |                       |
|      SL       | Slashing             |      slash       |                       |
|      TH       | Thrusting             |      thrust      |                       |
|      EVA      | Evasion             |      evade       |                       |
