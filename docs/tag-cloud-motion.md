# 标签词云动效修复 · 1.4.2

2026-11-05。范围仅为标签页，首页与共享 tooltip 实现未改动。

## 原因

生产构建的 CSS 顺序让 `.tag-token:hover` 覆盖同优先级的词云 `transform`。悬停时，代码中的缩放变量已经到 1.58，但浏览器实际样式是 `translateY(-2px)`、缩放为 1。变大的文字触发悬停后又缩回，移动中反复改变命中对象，导致提示框闪烁。仅查看动画变量无法发现这个问题。

旧逐帧循环还交错写入样式和读取每个词的尺寸；提示框每次 pointermove 都重新测量、定位，并在显隐或文章数改变时重新播放入场。

## 开源来源与适配

参考 [Magic UI Dock](https://github.com/magicuidesign/magicui/blob/58ee1feebc504a660c00087b369da511e913477e/apps/www/registry/magicui/dock.tsx) 的 MotionValue → useTransform → useSpring 组合。固定来源提交为 `58ee1feebc504a660c00087b369da511e913477e`；[MIT 许可](../public/vendor/magic-ui/LICENSE.txt) 随站点保留。

复用已有 Motion 14.9.0，无新依赖。原组件是单行图标 Dock，会修改宽高并读取动画节点边界，因此没有整段套用到二维词云：

- 排版时预留放大空间，链接位置和点击区域固定；只有内部文字执行弹簧缩放，不改变布局。
- 距离由缓存的排版坐标和共享指针 MotionValue 计算，动画帧不读取 DOM 尺寸，也不触发 React 状态更新。
- 去掉瞬时亮度变化和上下位移；同一元素的合成层不随悬停反复开关。
- tooltip 使用固定链接位置，只在目标变化时更新；跨过短空隙保留 100ms，显示期间改变文章数不重播入场。保留首页同款边框外观。
- 保留文章数权重、中心布局、随机文字颜色、筛选、原生 Tab/Enter 和触屏链接；减少动态模式不放大。

## 验证

在实际浏览器中检查生产构建的计算样式和真实矩形，而非只检查动画变量。对比路径包括慢速穿过相邻词、边缘停留、离开返回、筛选后重新悬停、减少动态模式与手机点击。未增加常驻动画测试或修改首页检查。

同一台机器、同一条 136 步相邻词横扫路径：提示框可见状态变化从 24 次降为首次出现的 1 次，重复 WAAPI 入场从 12 次降为 0 次。生产版链接矩形在悬停前后完全相同，文字计算缩放约 1.45；原生键盘和手机链接、筛选后动效均通过，页面脚本错误为零。该结果描述这条复现路径，不推断所有设备的帧率。

## 1.4.3 参数调整

桌面最大放大比例由 1.45 提高到 1.70，宽度小于 600px 且使用鼠标时由 1.20 提高到 1.30。触屏及减少动态模式保持不放大。默认字号、词云位置与间距、点击区域、弹簧、邻近作用半径和 tooltip 逻辑均保持 1.4.2 的设置，只调整悬停放大倍数。

## 1.4.5 局部弹性避让

沿用 1.4.4 的桌面最大 1.9 倍、窄屏鼠标 1.3 倍。默认字体和排版计算未变。局部求解器根据实际文字边界及随放大增加的留白推开邻词，目标位移限制为 36px；从原始排布重新求解，不把上次偏移累积进去。边界和位移上限优先于额外留白，不承诺任意高密度内容都能完全分离。

邻词使用 Motion 弹簧平移，原生链接随文字一起移动，放大文字外沿也能点击。切换焦点时捕获当前实际偏移并停止残余速度，将当前词锁在当时位置；静止指针不因邻词移动自动换目标，按下期间保持目标。离开词云后平滑归零。触屏与减少动态模式不启用避让。

实际生产预览的短路径检查：默认 godot 字号 39px、链接矩形与 1.4.4 相同；godot 放大时 pointer 左移约 10.18px、node2d 右移约 8.71px。慢速跨词、快速切换、边缘命中、回弹中重新进入、已移动词点击及原生键盘导航通过；最终 30 词偏移均回到 0，没有本次检查中的文字相交、横向溢出或页面脚本错误。未新增常驻动画测试。
