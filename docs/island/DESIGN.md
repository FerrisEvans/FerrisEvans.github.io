# 未尽 · 林间阅读庭院

> 本文区分最初的小岛原型与最终整合。早期布局草图保留当时的旧名 Praxis，不代表当前品牌；站点现用名为「未尽」。

基线：`08844b2`，从干净的 `astro-redesign` 创建 `codex/island-home-3d`。本次不推送、合并或部署。设计图 `layout-reference.svg` / `layout-reference.webp` 是布局参考，不是模型截图；原始 PNG 的仓库外归档见 [preview-compression.json](preview-compression.json)。

## 最终整合（2026-11-04）

- 交互场景直接属于 `/` 首页，不再设置独立小岛页或“探索小岛”按钮。首页本身就是宽幅庭院，一句小号介绍、阅读入口和全景按钮置于场景上方；页面 h1 为无障碍标题，不重复 Header 的大字标。物件与底部可访问导航承担首页功能，不再在场景下叠加普通文章列表与分类区。桌面 Header、轻量栏、舞台和物件导航约占一屏，页脚在后方正常排列。
- 首页、笔记、分类、标签、归档、关于直接列入同一个 Header；没有“更多”菜单。所有页面共用页脚、字体、明暗偏好和原库鼠标 SVG，拖动、文本、缩放、尺寸调整等原生鼠标语义保留。
- `/notes/` 是普通 HTML 笔记目录，分页使用 `/notes/page/<n>/`；简洁标题、文章总数、搜索和归档入口后保留真实分类、精选及文章列表。`/island/`、`/room/` 兼容跳转至 `/`，`/lofi/` 与 `/page/<n>/` 兼容跳转至笔记目录。文章 URL 不变，文章面包屑返回笔记目录；别名从 sitemap 排除。
- 首屏先显示当前主题的静态封面，首页自动加载真实 3D 并渐显。普通滚轮继续滚动页面，Ctrl/⌘ + 滚轮缩放场景；手机左右拖动环顾、向下滑动阅读。没有 JS、WebGL 或加载失败仍能阅读同页的文章与完整静态目录。
- 场景由早期封闭书屋改为开放林间阅读庭院，保留原创小熊及动画，环境转为已核验来源的 CC0 素材组合。完整采用范围、许可、来源与文件哈希以 [素材记录](../../scripts/island/SOURCES.md) 为准；不能沿用前一轮“仅四个外部道具”或第一轮“无外部模型”的描述。
- 站点标识为原创「翻开的书与嫩芽」，与作者小熊头像分开。可编辑源 `public/brand/island/mark.svg` 经 `npm run assets:brand` 生成各尺寸 favicon、ICO、兼容路径、manifest 和身份记录；页面使用同一个「未尽」字标与 `weijin-1` 资源版本。

## 原始方向与首版原型

从原阅读界面继承纸色、奶油色、棕色文字、薄荷与青绿色，以及 Nunito / Noto Sans SC、圆角、焦点和主题习惯。最初首页曾采用左侧介绍与入口、右侧场景封面，移动端上下排列，后方接最新文章与分类；该结构已由上节的完整场景首页替代。早期称为 LO-FI 的独立阅读入口也已合并为笔记目录，不再作为另一种模式展示。

场景是可环绕的微缩阅读岛：中后景书屋，前景小熊与书桌，左侧公告板，右侧分类路牌，树和小植物围合边缘，步道通往码头。小熊保留现有头像的棕色身体、圆框眼镜、嫩芽和绿色书本。物件不承载长篇 Canvas 文本。第一轮原型全部使用原创模型；第二轮加入四个 CC0 野餐道具，之后按最终整合方向重构为环境素材主导的庭院。以下旧物件表仅记录原始映射。

| 物件 | 行为 | 内容唯一来源 |
| --- | --- | --- |
| 书屋 | 开门，镜头靠近 | `getPosts()`、`postUrl()`；有限预览与完整目录 |
| 公告板 | 纸张轻抬 | 真实更新日期；有限最近文章 |
| 分类路牌 | 轻摆 | `categoriesFor()`、`categoryCounts()` |
| 小熊书桌 | 呼吸、眨眼、抬头、挥手 | ABOUT、ABOUT_GUIDES 三篇指南 |
| 吊牌 | 聚焦提示 | 文章标签集合与数量 |
| 信箱 | 翻盖 | SITE、RSS 与已有联系方式 |

没有自由行走、碰撞、实时文章贴图、自动声音、额外主题偏好或空宣传区。实验角延后，不能阻碍普通 Markdown 发布。

## 结构与迁移决定

- `src/utils/island-content.ts` 适配已发布内容；所有标题/链接为静态 HTML。
- `src/scripts/island/entry.ts` 管理加载、重试、可见性、生命周期与 UI；按需导入渲染器。
- `scene.ts` 负责渲染、材质、灯光和资源释放；`navigation.ts` 控制斜俯视范围；`picking.ts` 使用最近可见表面避免穿透；`animation.ts` 负责部件动作；`panels.ts` 增强已有 HTML。
- 继续复用经过验证的 `room/assets.ts` / `asset-cache.ts`：字节进度、SHA-256 校验、缓存异常降级、请求取消与重试。旧 CRT、录像带、电影缓存、纸面投影及固定模型名不是新约束。
- 通用发布、缓存、导航恢复契约保留在默认验证内；旧场景专属测试已随无用实现移除，并在迁移表记录替代关系与 Git 恢复点。旧资产不再进入源码交付或 `dist`。
- 一个原生 dialog 移动静态 section，避免复制标题 ID；浏览器返回、Escape 和关闭恢复入口焦点。加载中、无 JS 或 WebGL 失败仍保留同一套完整静态目录；正常场景就绪后隐藏目录，通过物件打开对应内容。

## 初始预算（目标，不是实测承诺）

| 项目 | 预算 |
| --- | --- |
| 首次可交互核心模型与脚本 | 约 5 MB 内 |
| GLB | 优先 3 MB 内；无高分辨率纹理 |
| 桌面 | 60 FPS 目标，实际 DPR 上限 2 |
| 手机 | 至少稳定 30 FPS 目标，DPR 上限 1.5；不按窄屏拒绝 3D |
| 三角面 | 优先 100k 内，有限材质与光源 |
| 阴影 | 一个方向光阴影，2048²；无重型后处理 |
| 隐藏页 / 减少动态 | 隐藏页停止 RAF；减少动态按操作渲染，不运行环境循环 |
| 首页 | 当前主题封面优先展示，自动加载真实 3D；面板与失败退路使用同一套 HTML，直接访问笔记目录不加载模型 |

实际测量须记录浏览器、设备、分辨率、DPR、冷缓存、资源大小、帧时间；浏览器手机模拟不能代替真机。

## 阶段验收

1. 现状、视觉体系和数据来源核实；提供设计参考与预算。
2. 先验证相机、拾取、静态目录增强、真实分类、触摸和返回；`?greybox=1` 可检查空间布局。
3. 对小熊及主要环境物件的实际网页近景/全景/竖屏截图评估造型、阴影、动作；先修正再推广。
4. 从首页 `/?capture=1` 的同一 WebGL 场景捕获浅/深封面、加载图、分享图；统一首页与阅读导航。
5. 发布生命周期、无 JS、无 WebGL、加载失败重试、历史恢复、减少动态及后台暂停回归；确认交付中不含旧场景资源。
