# 1.4.1 · 资源传输优化

2026-11-05，Asia/Singapore。复用旧版书房的离线压缩、内容哈希与持久缓存思路；不改变小岛布局、建模精度和动画。

| 资源 | 优化前 | 优化后 | 口径 |
| --- | ---: | ---: | --- |
| 模型文件 | 4,899,572 B | 1,890,820 B | 源 GLB 对比 Meshopt + 无损 WebP + gzip，减少 61.4% |
| 线上模型下载 | 2,482,359 B | 约 1,890,820 B | 原站已启用 HTTP gzip；预计模型传输减少约 23.8%，不应宣称下载减少 61.4% |

原站模型下载大小来自实际线上 `Accept-Encoding: gzip, br` 响应的 `Content-Encoding: gzip` 与 `Content-Length`。压缩模型还需要 Three.js 已附带的 Meshopt 解码模块，源模块约 29 KB；它随场景代码拆包，并非全站静态页面的必需下载。以上不代表 FPS 或 GPU 内存改善。

## 保留画面与可编辑源

- 原 GLB 移到 `assets/island/island.glb`，Blender 源和全部 CC0 原素材继续保留；发布目录只放压缩交付文件。
- Meshopt 不做量化、顶点重排或减面。打包器逐项核对 182 个节点、114 个 mesh、41 个材质、三个动画，以及每个三角面上的属性原始数值和绕序。
- 十张纹理的尺寸不变，WebP 解码后的 RGBA 像素与 PNG 逐字节一致。保留所有几何属性；不通过删除细节换取体积。
- `transport.json` 固定源、打包器、压缩前后字节和 SHA；相同输入重复打包结果逐字节一致。`assets:model` 完成打包与封存，`assets:check` 拒绝过期产物。
- 头像原 PNG 移到 `assets/brand/`。`assets:brand` 可重新生成公开 WebP，记录在品牌 identity receipt 中。

## 加载与缓存

继续使用原有 SHA 校验、CacheStorage 持久缓存、坏缓存恢复和 HTTP 降级。模型下载与场景脚本并行；缓存保存 1.89 MB 的交付字节，进入实际场景时才展开 gzip 和 Meshopt。

修复单模型入口未调用旧版本清理的问题：场景 ready 后后台清理该模型 URL 的历史 revision，保留当前和上一版，不重复下载或哈希，也不阻塞场景显示。其他资源路径与其他应用缓存保持原策略；这不是清空旧书房所有浏览器缓存。

## 本次未采用

旧版的分级烘焙光照不适合全岛同时可见、没有大体积 irradiance 贴图的当前场景。没有引入额外的低清场景、物件延迟出现或有损法线/UV 量化。

首页已有冷启动记录显示字体下载约 2.41 MB，其中两种 Noto Sans SC 字重约 2.33 MB。它们已经是 WOFF2；直接换系统字体会改变跨设备排版，本次保留。后续可单独评估覆盖全部字符的 Unicode 分片，避免恢复每次写文章都要人工补字的流程。

专门的 3D 动作、眨眼、镜头和描边浏览器自动验收仍维持删除状态。验证使用打包内的数据完整性核对、现有基础检查和实际浏览器查看。

本地封面重新通过压缩后的实际浏览器渲染生成：日间、夜间、分享三张图与优化前解码后的像素完全一致，变化像素为 0。类型检查、现有 66 项基础检查、生产构建与静态引用验证通过。未用文件压缩率推断 FPS 改善。

## 同版交互调整

- 标签词云移除下划线，复用首页边框提示框显示文章数；字号与中心位置取决于文章数。鼠标接近时按距离平滑放大，目标最大约 1.58 倍，邻词跟随；触屏和减少动态模式保留原生导航。
- 加载图保存实际场景的正交投影边界，按相同比例适配屏幕；已绘制的画布直接显示，只淡出上层加载图，避免双层透明度变化露出背景。1440×900 与 390×844 的实际浏览器中，加载前后 stage/canvas 尺寸完全一致，投影比例一致，无页面滚动。
- 水平旋转开放整圈，俯仰范围扩大到距垂直约 24–77°，保留地面以上视角。从反方向关闭阅读面板时，沿最短环绕路径返回，避免穿过小岛。
