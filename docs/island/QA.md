## 交付行为

- 首页就是可交互小岛，默认全岛一屏，无外层横纵滚动条、数字标记、底部物件导航或“回到全景”按钮。普通滚轮缩放，拖动环顾，触屏单指环顾、双指缩放。六个实际物件和六个原生键盘按钮打开相应内容；关闭、Escape、历史返回都平滑回默认构图。
- 小狗闻花、观察、摇尾；小兔持壶浇花；小熊阅读翻页。三位朋友都有自然眨眼。悬停狗会招手，兔会停下浇水抬头摆耳，熊会暂停阅读回应；兔和熊没有点击入口。减少动态时停止持续活动，保留静态轮廓反馈。
- 八个悬停目标统一使用淡入细描边，不再整物件发亮。书本抽出、翻页/台灯、喷泉喷水、植物枝叶和收音机音符保留各自特征。功能入口气泡只显示用途；共享 tooltip 不再污染所有按钮的读屏描述。
- 小狗俯视鼻口改为连续闭合曲面，小兔与小熊更圆润。兔棕色部分为带真实颈孔、绕肩背的薄布领口，两颗纽扣贴合下角。原熊源模型与动作保留。庭院宽深各增加8%，增加嗅花架和花圃等活动布景。见 [模型复查](model-quality.md)。
- 标签页是纯文字词云，无胶囊背景、边框、圆角；保留大小层级、随机文字色、筛选和原生 Tab/Enter，无自定义方向键导航。首页关键词保留 Animal Island UI soft Tag 形式。
- 原创“未尽”中文字标、书芽图形与 favicon 统一使用。关于页和首页作者面板使用新生成的卡通狗头像，没有把用户照片当头像；[生成记录](avatar-generation.md)保留提示词与来源。
- 页头直接列出首页、笔记、分类、标签、归档、关于；全站指针规则统一。`/island/`、`/room/`兼容跳转首页，`/lofi/`跳转笔记。
