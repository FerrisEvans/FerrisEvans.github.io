## 本轮交付

- 首页本身就是3D小岛；无独立探索入口、底部物件导航、数字标记或“回到全景”按钮。桌面和手机默认构图均显示整个岛，页面占一屏，无横纵滚动条；内容弹窗与失败目录在内部滚动。
- 普通滚轮直接缩放，单指拖动环顾、双指缩放。点击真实物件打开HTML内容；关闭X、Escape、历史返回均平滑回到默认构图。鼠标进入的面板关闭后焦点回场景，键盘进入则精确回原按钮。
- 六种悬停反馈：书本抽出、书页翻动及台灯亮起、喷泉喷水、小狗招手摇尾、枝叶摆动、收音机音符。固定盆不摆动，水滴与涟漪落在真实池面。带边框的island气泡只显示功能名。减少动态时保留静态高亮，不持续播放水流、音符或角色动作。
- 首页关键词使用实际Animal Island UI soft Tag组件与语义颜色，每次打开重新配色。标签页仅保留标题说明、筛选和无边框词云；删除第二份全标签列表、字体/方向键说明和自定义方向键导航。原生Tab/Enter链接仍有效。
- 原创SVG“未尽”字标与书页嫩芽图形统一用于页头、页脚及站内品牌位置；没有独立草绿色圆点。favicon与深浅色标志一致。页面标题、元数据和无障碍名称保留文本。
- 黑色小狗成为关于入口与作者形象，小兔、小熊同住岛上。关于页和首页介绍均使用新生成的卡通狗头像；原照片不作为网站头像。原熊模型、动画与旧插画保留。[头像及完整生成提示词](avatar-generation.md)

`/island/`、`/room/`兼容跳转到`/`，`/lofi/`跳转到`/notes/`。页头直接列出首页、笔记、分类、标签、归档、关于；全局原生自定义指针沿用已有统一规则，输入、拖动等语义指针保留。

## 建模复查与来源

[模型质量检查](model-quality.md)包含角色三视图、挥手姿势、书架/植物/野餐近景、实际发现的问题与修正。完成源模型接触关系和枝叶拆分检查后，再在真实WebGL中复查默认构图、六个可点击物件和动态效果。Blender静态预览与浏览器截图明确区分。

最终GLB **4,530,208 bytes**，SHA256 `fcc256d469e3cd548d2140c1a5763a421011c3ffaa94d6f815e2410844089a04`；123,736个唯一mesh三角形、109 meshes / 110 primitives、40材质、10内嵌图片 / 15 texture记录。primitive数不是实际draw calls。模型仍在原5 MB预算内；该限制不等于整个首页冷加载低于5 MB。

实际采用五包共58种模型：Pretty Park 21、Pleasant Picnic 12、House Plants 9、Furniture Bits 8、Forest Nature 8。原源文件、CC0许可、SHA-256和导出extras集合核对通过，没有宣称使用未取得的Kenney包。用户照片参考的狗、兔是独立原创几何，不能误记为CC0供应商模型。[来源](../../scripts/island/SOURCES.md) · [报告](../../public/island/model-report.json) · [可编辑Blender](../../assets/island/island.blend)
